# Umgang miteinander

Hier treffen sich Eltern, Bastler und Neugierige. Ein paar Sätze reichen:

- **Freundlich bleiben.** Auch wenn eine Frage schon dreimal gestellt
  wurde, auch wenn der Code jemandes erster Versuch ist.
- **Kein Vorwissen voraussetzen.** Wer hier landet, will meistens einfach
  nur ein Tablet an der Küchenwand. Das ist ein völlig legitimer Grund.
- **Kritik gilt der Sache, nicht der Person.**
- **Keine Beleidigungen, keine Herabwürdigung**, egal woran jemand
  festgemacht wird.
- **Privates bleibt privat.** Keine fremden Daten, keine Screenshots mit
  echten Namen oder Kinderfotos.

Wer sich nicht daran hält, bekommt einen Hinweis. Wenn das nichts nützt,
werden Beiträge entfernt und im Wiederholungsfall der Zugang gesperrt.

Etwas gemeldet werden kann über [familienfabrik.at](https://familienfabrik.at).
Meldungen werden vertraulich behandelt.
